# Angira Yadav — Personal Portfolio

A personal portfolio and engineering showcase built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS v4**.

---

## ⚡ Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons & Motion**: Lucide React, Framer Motion
- **Deployment**: Vercel

---

## 🌟 Features

- **Responsive & Modern UI**: Smooth micro-interactions, subtle floating animations, and adaptive layout.
- **Dark & Light Mode**: Instant toggle with local storage persistence and zero flash of incorrect theme.
- **Projects Showcase**: Interactive project cards with pop-up architecture breakdowns, live deployment links, and GitHub repositories.
- **Certifications & Specializations**: Industry credentials (Oracle Cloud, Coursera, Samsung SIC, NPTEL) with verification links and view-all toggle.
- **Skills Matrix**: Interactive category filtering across Programming Languages, Core CS, Web Technologies, AI/ML, and Developer Tools.
- **Education & Distinctions**: Academic history (SRMIST Chennai, VidyaGyan School) with scholarships and honors.
- **Interactive Contact**: Direct email copy button and social profile links (GitHub, LinkedIn).

## 🚀 Getting Started

### Prerequisites
- Node.js 20.x or higher
- npm 10.x or higher

### Installation & Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/angirasny7/Personal-Portfolio.git
   cd Personal-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   npm run start
   ```
